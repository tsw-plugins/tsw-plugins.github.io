# tsw-plugins.github.io

Documentation home for the [tsw-plugins](https://github.com/tsw-plugins) organisation: mods for
Train Sim World 7. The code repositories carry only a `README.md` and an `AGENTS.md`; everything
else lives here, published at <https://tsw-plugins.github.io/>.

| Folder | What is in it |
| --- | --- |
| [`plugins/`](plugins/) | One page per plugin; tsw-coop's documents and its session browser (`plugins/tsw-coop/sessions/`) |
| [`sdk/`](sdk/) | Guides and reference for writing plugins against tsw-sdk (planned) |
| [`design/`](design/) | Design documents and proposals, each with a `status` |
| [`research/`](research/) | Findings about the game, UE4SS and our tooling |

Plain Markdown with YAML front matter, rendered by GitHub Pages' built-in Jekyll; there is no
generator or workflow. Research notes state the game build they were verified on. The history
of the documents before 2026-10-18 comes from
[tsw-coop](https://github.com/tsw-plugins/tsw-coop)'s `docs/` and `site/`.
